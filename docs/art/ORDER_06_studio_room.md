## 붙여넣을 것

첨부한 이미지 4장이 이 게임의 화풍 기준이다.
화풍을 설명한 문장이 아니라 **그 이미지를 따라라** — 색조, 붓질, 외곽선 두께, 명암, 밀도.

만들 것은 게임에 붙일 **부품**이다. 완성된 게임 화면이 아니다.

반드시 지킬 것
- 첨부 이미지와 같은 화풍·색조
- **UI를 그리지 마라** — 버튼, 패널, 카드, 아이콘, 말풍선, 게이지, 상단 바, 가방
- **글자를 넣지 마라.** 단, 세계 안에 실재하는 간판·표지판·현수막·게시물은 예외 (한국어)
- 워터마크·서명·테두리·액자 없음
- 한 번에 하나만

하지 말 것
- 게임 화면처럼 보이게 구성하기
- 사진처럼 사실적인 렌더링, 3D 렌더 느낌
- 앵커보다 밝거나 채도가 낮은 톤

**장면: 한개미의 원룸**

주인공이 혼자 사는 원룸. 밤.
좁다. **매트리스는 프레임 없이 바닥에 놓여 있고**, 라면 상자에는 몇 개 안 남았다.
낡은 노트북이 열려 있고, 그 옆에 이달 급여명세서가 있다.
달력에는 25일에 동그라미가 쳐져 있다 — 월급날이다.
창밖으로 도시의 불빛이 보이지만 방 안은 어둡다.

세로 구도. **폭 : 높이 = 2 : 3 — 1024×1536.** 폭 1024는 고정.

> **여유는 낭비가 아니라 설계다.** 월드 밴드(942×1305)의 비율은 1:1.385 라
> 위아래로 약 59px씩 잘린다. **그래야 한다** — `bg_anchor` 로 잘라내는 위치를 움직이고,
> 배틀 화면(월드 44%)에서 같은 그림을 더 넓게 잘라 쓰고, 하단 패널 높이가 바뀌어도
> 재발주가 안 생긴다. (아트 기준 §4 「넉넉히 그리고 화면이 세로로 잘라 쓴다」)

인물 없음. 빈 방이다.

화면 안에 있어야 하는 것 (가로 위치는 왼쪽부터의 비율):

| 무엇 | 가로 위치 |
|---|---|
| 창문 | 4–22% |
| 급여명세서 | 24–32% |
| 낡은 노트북 | 33–48% |
| 직장인 가방 | 35–46% |
| 라면 상자 | 53–63% |
| 냉장고 | 64–76% |
| 달력 | 78–92% |
| 매트리스 | 7–30% |

나가는 곳:

| 무엇 | 가로 위치 | 비고 |
|---|---|---|
| 현관문 | 84–99% | 나가는 곳이다. 문이나 통로로 읽혀야 한다 |

- **인물이 걸어다니는 바닥 띠가 화면 세로 60~95% 구간에 들어와야 한다.**
  그 띠의 위쪽 끝(먼 쪽)이 73%보다 아래로 내려가면 안 된다
- 위 목록의 물건들은 **배경에 묻히지 않게** 또렷이 읽혀야 한다. 플레이어가 눌러야 하는 것들이다
- 가운데를 비워 둔다 — 인물이 그 앞에 선다
- **매트리스에 프레임이 없어야 한다** — 게임이 그렇게 말한다
- 달력의 동그라미가 보여야 한다
- 살림이 적다. 채워 넣지 마라. 비어 있는 것이 이 방의 성격이다

## 받으면

**여러 장 뽑아서 그중 하나를 고른다.** 프롬프트 끝에 「서너 장 만들어 줘」를 덧붙이면 된다.

| 볼 것 | |
|---|---|
| **화풍 · 분위기 · 구도** | **눈으로 본다.** 앵커 4장 옆에 나란히 놓고 같은 세계로 보이는지 |
| 위 목록이 다 있는가 | 빠지면 그 핫스폿을 누를 수 없다 |
| 바닥 띠가 60~95% 인가 | 위쪽 끝이 73%보다 내려가면 대화 중에 인물이 잘린다 |
| UI가 그려졌는가 | 버튼·패널이 있으면 프롬프트가 안 먹은 것이다 |
