## 4b. 플레이 피드백 반영 (1차)

실제 플레이 후 받은 지적 두 가지를 반영했다.

### "반응이 답답하다 / 포커스 깜빡임이 너무 길다"

| 항목 | 이전 | 이후 |
|---|---|---|
| 마우스오버 포커스 | 0.6초 주기 점멸 (절반은 안 보임) | **상시 표시**. 점멸은 눈이 아프고 "반응이 없나?" 하는 착각을 준다 |
| 커서 | 핫스폿 위에서 0.5초 주기 점멸 | 상시 강조 + 십자가 조여드는 형태 변화 |
| `보다` 동작 | 대상까지 걸어간 뒤 대사 (최대 2~3초) | **걷지 않는다.** 고개만 돌리고 즉시 대사 |
| 걷는 중 클릭 | 무시됨 | **새 목표로 즉시 전환** (진행 중 행동 취소) |
| 이동 속도 | 62 px/s | 90 px/s |
| 자막 (30자, '보통') | 3.4초 | 1.8초 |
| 장면 전환 암전 | 264ms | 120ms |

`보다`만 즉시 반응하게 한 이유: 눈으로 하는 동작은 거리와 무관하고, 조사가
가장 빈번한 행동이라 여기서 지연이 체감의 대부분을 만든다. 물건을 집거나
쓰는 동작은 여전히 걸어간다 — 그게 없으면 공간감이 사라진다.

### "독백이 너무 이성적이다 / 투덜대게"

한개미 대사 **165개를 전면 재작성**했다. 투덜대고, 감정이 먼저 나오고,
자기합리화하고, 종결어미가 짧다.

```
이전: "디카페인 원두를 챙겼다. 카페인만 빠진 커피. 겉으로는 똑같다."
이후: "일단 챙겼다."
      "카페인만 뺐다는데 그럼 뭐가 남는 거야. …아니 잠깐. 겉으로는 똑같잖아."
```

손대지 않은 것:
- `narrator` 대사 — §8.1 원문 인용이고, 투덜대는 한개미와 대비되어야 여운이 남는다
- §8.1 선택지 4개, §10.2 사원증 설명 — 명세서 원문
- 날카로운 한 방 2~3개 (§0-6 "무능한 바보가 아니다", §24 "한 박자 늦게 깨닫는 농담")
  예: "방송 차트랑 우리 매출표가 똑같이 생겼다. 둘 다 오른쪽이 비어 있네."

## 4c. 플레이 피드백 반영 (2차)

### "대사가 뜨는 속도가 너무 빨라"

1차에서 "반응이 답답하다"를 클릭 반응 지연으로 읽고 타자 속도까지 같이 올렸는데
그게 과했다. 둘을 분리했다 — **글자가 찍히는 속도는 느리게, 다 찍힌 뒤
붙잡는 시간은 짧게.**

| | 원래 | 1차(과했음) | 2차 |
|---|---|---|---|
| 타자 속도 (보통) | 26 cps | 42 cps | **20 cps** |
| 30자 대사가 찍히는 시간 | 1.15초 | 0.7초 | **1.5초** |
| 다 찍힌 뒤 홀드 | 2.25초 | 1.12초 | 1.23초 |
| 합계 | 3.4초 | 1.8초 | **2.7초** |

### "대사 글씨를 조금 더 도트느낌 나게"

`SystemFont`(Apple SD Gothic Neo)는 크기만 작을 뿐 곡선이 매끄러운 현대
고딕이라 도트 느낌이 안 났다. **Galmuri** 한글 도트 폰트(OFL 1.1)로 교체했다.
Godot 임포터가 스스로 "Pixel font detected"로 인식하고 subpixel/hinting 을
끈다 — 진짜 비트맵 설계 폰트라는 확인이다.

핵심은 **설계 크기로만 쓰는 것**이다. Galmuri11 을 9px 로 줄이면 리샘플링되어
도트가 뭉개진다. 그래서 크기 단계마다 폰트를 따로 둔다(9/11/14px).
`Theming.small_font` 도 같은 이유로 추가했다 — 좁은 칸에서 크기만 줄이면
안 되고 더 작은 폰트로 갈아타야 한다.

### 폰트 교체로 드러난 레이아웃 문제

11px 폰트는 이전 10px보다 크므로 촘촘한 목록이 깨졌다.

| 문제 | 수정 |
|---|---|
| 설정 13항목이 행 높이 11px에 11px 글자로 붙어버림 | `MenuList.dense` 추가 — 작은 도트 폰트(9px) + 행 12px. 제목만 본문 크기 유지 |
| 저장 슬롯 13개도 같은 문제 | 같은 처리. 썸네일 정보 폭도 넓혀 저장 시각이 안 잘리게 |
| 타이틀 부제목이 양초 위에서 금색이라 묻힘 | 아이보리 + 외곽선. PNG 픽셀을 직접 샘플링해 검증했다 |
| Godot 이 `docs/screenshots/` 를 게임 에셋으로 임포트 | `.gdignore` 추가 |
