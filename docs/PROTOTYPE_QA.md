## 2. 실행 중 발견해 고친 실제 버그

| # | 버그 | 원인 | 수정 |
|---|---|---|---|
| 1 | 장면 파일이 전혀 안 읽힘 | `GameData._merge_keyed` 가 `{"scene_id": ...}` 단일 오브젝트 형태를 처리 못 함 | 세 가지 문서 형태를 모두 지원 |
| 2 | **이어하기가 옛 저장을 염** | 자동 저장이 같은 초에 여러 번 → `saved_at_unix`(초 단위)로 순서 구분 불가 | 단조 증가 `save_index` 도입 |
| 3 | 컷신 문구가 대화 기록에 안 남음 | `CardView` 가 `DialogueLog` 에 기록하지 않음 | 카드 문구도 기록 (§18) |
| 4 | 컷신 중 조작 잠금이 풀림 | `event_requested` 시그널 emit 이 핸들러를 await 하지 않음 | await 가능한 `event_handler` Callable 로 변경 |
| 5 | '즉시' 텍스트 속도가 가장 느림 | `length / max(cps,1)` 에서 cps=0 → 글자 수만큼 초가 됨 | cps=0 이면 타자 시간 0 |
| 6 | 머그컵이 모니터 위에 겹쳐 그려짐 | 좌표 겹침 | 책상을 넓히고 재배치 + 검증기에 기하 검사 추가 |
| 7 | 실패음이 '보다'에서도 울림 | 조사도 실패로 취급 | LOOK 제외 + 결과가 sfx 를 지정하면 존중 |

## 3. 진행 불가 시나리오 — 자동 확인됨

- ✅ 컵 관찰 전/후 어느 순서로 진행해도 막히지 않음
- ✅ 라벨 재수령 시도 → 고유 대사, 상태 불변
- ✅ 커피를 싱크대에 버리려 함 → 거부, 아이템 유지 (§11.2)
- ✅ 부장 대화 선택지 소진 → 대화가 짧게 종료, 재대화 가능
- ✅ 부장 퇴장 후 부장 핫스폿 클릭 불가
- ✅ 전제조건 실패 시 아이템 소모 안 됨
