TERRITORY

계층 구조

소속의 기준 단위는 동네(시·군·구) 하나다. 동(洞) 이하는 사용하지 않고, 실존 기관(학교·직장 등)도 소속으로 사용하지 않는다. 누구에게나 사는 동네는 있고, 그거면 충분하다.

유형데이터표시
동네 필수행정구역 (시·도 / 시·군·구). GeoNames 또는 각국 공공데이터 기반 정적 JSON 3~6MB 초회 다운로드항상 표시
크루 선택유저 생성동네 뒤에 괄호로 표기. 없으면 괄호 자체가 표시되지 않음

크루

  • 유저가 직접 결성하는 모임. 인원 상한 30명, 동네 하나에 귀속된다
  • 「기흥구 야근조」, 「동백동 새벽러너」처럼 자기들끼리 이름 짓는 구조
  • 크루 랭킹은 소속원 상위 10명 평균으로 집계한다. 인원이 많다고 유리하지 않으므로 소규모 크루도 1등을 노릴 수 있다
  • 크루명은 로케일별 금칙어 필터 적용. 크루장 30일 무활동 시 자동 이관

변경 정책

  • 동네 변경은 시즌당 1회만 허용 — 약한 지역을 옮겨 다니며 1등을 수집하는 행위 차단
  • 변경 시 해당 시즌 기록은 이전 동네에 남고, 신규 동네는 다음 시즌부터 집계
  • 크루 가입·탈퇴는 자유. 단 탈퇴 후 7일간 재가입 불가

랭킹 & 시즌

RATING

레이팅 — Elo

같은 점수대 상대를 이기면 적게, 고득점자를 이기면 많이 오른다.

기대승률 E = 1 / (1 + 10^((상대점수 - 내점수) / 400))
점수 변동  Δ = K × (실제결과 - E)      // 승=1, 패=0

왜 총합이 아니라 상위 평균인가

크루 랭킹을 총합으로 하면 인원 많은 크루가 무조건 이긴다. 상위 N명 평균이어야 소규모 크루도 1등을 노릴 수 있고, 그래야 소속감이 실제로 작동한다.

시즌

  • 8주 1시즌, 종료 시 소프트 리셋: 신규점수 = (현재점수 + 1000) / 2
  • 각 계층 1위에게 영구 칭호 부여 (예: 2026 S1 기흥구 챔피언)
  • 시즌마다 지역 대항 이벤트 주간 운영 (주말 48시간, 승수 합산)

카메라

  • 측면 고정, 궤도 회전 없음. FOV 30° 내외의 약한 원근만 사용
  • 두 캐릭터 거리에 따른 자동 줌. 줌 속도에 프레임당 상한을 둬 화면이 출렁이지 않게
  • 연출 카메라(각성기 컷인, 마무리 히트)는 시뮬레이션과 완전 분리 — 판정에 1프레임도 영향 없음
  • 롤백 중에는 연출 카메라를 재생하지 않는다. 롤백 발생 프레임은 카메라를 기본 상태로 즉시 스냅

깊이축 — 5레인 이산화

  • 깊이는 연속값이 아니라 5단계 레인. 판정이 명확해지고, 고정소수점 결정론 유지가 쉬우며, 네트워크 환경에서 "미묘하게 빗나감"이 사라진다
  • 공격 판정의 깊이 허용치는 ±1레인 — 인접 레인까지는 맞는다
  • 레인 이동에 4프레임 전환 시간, 전환 중 공격 불가
  • 종목별 차등: 체조선수 2프레임(기동형) / 씨름꾼 6프레임(둔중형)
  • 화면상 레인 차이는 Y 오프셋 + 그림자 위치 + 미세 스케일로 표현. 블롭 그림자가 깊이 정보의 주된 전달 수단
  • 콤보 진행 중에는 두 캐릭터의 레인이 락(고정)된다
FIG.2 — 깊이 5레인 · 논리 좌표와 화면 표현
이산화하는 이유: 깊이가 연속값이면 온라인 환경에서 "0.3레인 차이로 빗나감"이 생기고, 유저는 그 억울함을 넷코드 탓으로 인식한다. 5레인 + ±1 관대 판정은 판정 결과를 눈으로 예측 가능하게 만들기 위한 선택이다.

온보딩

계정 생성 직후 반드시 거치는 단계. 3분 안에 끝나도록 설계한다.

최초 실행 → 언어 선택 → 소속 지정(국가/시도/시군구) → 캐릭터 생성 → 튜토리얼 → 첫 매치
단계선택 항목비고
1. 베이스체형 2종골격만 다름. 판정·능력치는 완전 동일
2. 피부톤8종전 세계 대상이므로 톤 범위를 넓게, 한쪽에 치우치지 않게 배분
3. 얼굴형모프 슬라이더 4개턱선·광대·눈 크기·눈매 각도
4. 이목구비눈 20 / 눈썹 12 / 코 10 / 입 10텍스처 UV 교체 방식
5. 헤어24종 × 컬러 16유일한 추가 메시
6. 액세서리10종안경·마스크·헤어밴드 등
7. 기본 의상민무늬 티셔츠 + 바지 1벌 × 컬러 12색무늬·로고·장식 없음. 소속 동네의 기본색을 자동 제안
  • 랜덤 버튼 필수. 커스터마이징에 관심 없는 유저가 한 번에 넘길 수 있어야 한다
  • 얼굴은 계정 단위 아바타다. 전 종목에 동일하게 적용된다. "기흥구의 나"라는 한 사람이 검도가도 하고 씨름꾼도 하는 개념 — 지역 소속 게임의 정체성과 맞고, 제작 비용도 얼굴 세트 1개로 끝난다
  • 얼굴·헤어 재변경은 언제든 무료
  • 스킨(의상)만 종목별로 따로 장착한다

2.5D 구현 방식

  • 얼굴 메시를 바꾸지 않는다. 단일 헤드 메시 + 모프 타겟(블렌드셰이프)으로 얼굴형·눈 크기·눈매 각도를 조절하고, 눈·눈썹·입은 텍스처 아틀라스에서 UV 오프셋만 교체
  • 셀셰이딩 툰이므로 눈·눈썹이 평면 텍스처여도 어색하지 않다
  • 결과: 파츠가 수백 개여도 메시 1개, 드로우콜 1개
  • 헤어만 별도 메시(로우폴리 400~800tri), 컬러는 셰이더 팔레트 파라미터
  • 부수 효과로 표정 애니메이션(피격 찡그림, 승리 미소)이 따라온다

기본 의상

  • 메시 1벌 + 컬러 팔레트가 전부. 무늬도 장식도 없으므로 텍스처 작업이 거의 들지 않는다
  • 이 한 벌이 전 종목에 공통으로 쓰인다
  • 스킨을 하나도 갖지 않은 상태의 기본 외형이며, 학생·성인 어느 쪽에도 어색하지 않다

폰트

위 결정의 대가로 내 언어의 폰트만으로는 부족하다. 한국 유저가 일본 유저와 매칭되면 일본어 글리프가, 러시아 유저와 붙으면 키릴 문자가 필요하다.

문제해법
CJK 폰트는 각 10~20MB. 한·중·일 전부 넣으면 40MB+언어팩 온디맨드 — 기본 빌드에는 라틴 + 사용자 언어만. 매칭 시 상대 스크립트 팩을 자동 다운로드(수 MB, 5초 입장 연출 뒤에 숨는다)
글리프 수가 많아 아틀라스가 터짐SDF 동적 폰트 아틀라스 — 런타임에 필요한 글리프만 생성. 한 경기에 뜨는 지역명은 몇 개뿐
스크립트마다 폰트가 달라 디자인이 깨짐Noto Sans 계열로 통일
텍스처에 구워진 글자는 번역 불가UI 텍스트를 텍스처에 굽지 않는다. 전부 런타임 렌더

텍스트 확장

  • 독일어·러시아어는 영어 대비 30~40% 길어진다. CJK는 짧아진다
  • UI는 영어 기준 +40% 여백으로 설계. 격투게임 HUD는 공간이 빡빡해 나중에 늘릴 수 없다
  • 버튼 라벨은 자동 축소(auto-shrink) + 잘리면 툴팁
  • 순위 표기가 언어마다 다르다 — 3rd / 3位 / 3위 / 3.º → ICU 포맷

음성 — 비언어

  • 기합·신음·호흡 등 비언어 보이스만 사용 → 로컬라이제이션 비용 0

  • 승리 대사도 텍스트 말풍선 또는 이모트로
  • 자유 채팅 미탑재 → 실시간 다국어 모더레이션 부담 없음. 대신 프리셋 이모트·스티커로 소통

위임 불가 영역
